The adapter's historical 38 regexes and five summary features are explicitly defined. Corrected comments are scanned once; quoted text remains in pattern counts by declaration, while pragma extraction excludes quoted text. These are lexical heuristics. The initial all-source coverage snapshot is preserved; a later independent review added strict pattern-training and training-ID/source-hash guards. [The API amendment](adapters_v1/api_amendment_after_coverage.json) verifies unchanged pure preprocessing functions and identifies the final source snapshot.

The performance module estimates AP using a nonlinear weighted empirical distribution. Its Rao–Wu rescaled bootstrap is checked for the finite-population linear-total variance identity; that identity is not a proof of percentile-AP interval coverage. Unknown reference outcomes suppress AP point/interval estimates. HT workload estimates remain unclipped and can exceed a review budget in a sample; estimated unresolved-outcome endpoints and approximate sampling envelopes are distinguished from hard finite-population completion bounds. Zero estimated spread does not establish certainty about unsampled cases. All inference conditions on the fixed population, scores and expert-reference process; it does not cover new families, semantic grouping uncertainty, training variation or reviewer error.

The current performance API does not implement weighted recall ratios, paired method-difference intervals, cross-class covariance, multiple-comparison adjustment, model-training uncertainty, failed-tool/common-success analyses, or a rare-positive AP coverage study. Its complete-score requirement must not be relaxed by dropping failed files or inventing safe scores.

The toolchain's 2,689 source rows retain 2,650 compiler plans (1,968 external and 682 training) and 39 unavailable plans. Installing executables does not turn these plans into successful analysis. The [v2 verifier](toolchain_v1/verify_toolchain_v2.py) is read-only by default, creates a receipt only at an explicitly supplied new path and retains explicit validation under optimized Python. A separate `python -O` run verified all 30 compiler and 47 wheel hashes without executing any tool. Seven original and seven amendment tests passed; original v1 manifests, receipts and scripts remain unchanged historical snapshots.
