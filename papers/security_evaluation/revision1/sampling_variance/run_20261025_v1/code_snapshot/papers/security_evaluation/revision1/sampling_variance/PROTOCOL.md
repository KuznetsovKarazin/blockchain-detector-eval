# Conditional training variation on the historical pilot

This analysis addresses the reviewer's request to measure variation due to training-subset selection. It is an explicitly authorized **historical-pilot diagnostic**, selected after seeing the first pilot. It is not a confirmatory detector comparison, a new independent test, a repair of expanded-graph dependence, or external evaluation. The existing comparative and external campaign gates remain unchanged and blocked. Their evidence file is hash-bound into this run.

The exact original already-scored T contains 1,082 historical DAppSCAN files and 21 published SWC-107 findings in one historical joint component. It is not resampled or reselected. Published absence of a finding is a proxy zero, not an expert-confirmed safe label. Original membership, predictions, source inventory, annotation input hashes and pinned data revisions are checked before execution.

For each of 20 draw indices 0–19, use the original SHA256 path ranking salt and a common per-class rank across the four original regimes: unrestricted other files, project-disjoint, clone-disjoint, and their transitive joint restriction in the original 7,080-vertex graph. Each training sample contains exactly 1,179 files and 31 proxy positives. The original graph is unchanged; labels and scores do not redefine components. Draw zero must reproduce all four original training memberships exactly. The shared ranks pair the draws across regimes; they do not create independent test replications.

Run raw-text TF-IDF logistic regression, normalized-text TF-IDF logistic regression, pattern random forest (500 trees), and pattern LightGBM (400 estimators), with the fixed historical hyperparameters in `campaign.model_config()`. No tuning, model selection, feature selection by test score, or score-dependent stopping is allowed. Vectorizer and scaler fit on training data only. LR native threads=1; tree OpenMP/n_jobs=4 and BLAS=1. Report observed pools and cumulative process peak RAM.

For the main panel, estimator seed stays zero: variability then reflects training membership, not changes in tree random seeds. The full joint pool is already exactly 1,179/31, so all 20 joint training samples are identical. Reuse a fit when the ordered training/test memberships, method and estimator seed are identical, retaining the logical evaluation and reuse provenance. This is 320 main logical evaluations and normally 244 distinct main fits. The separately labelled joint estimator-seed panel uses the same complete joint training pool and tree seeds 0–19. Seed zero reuses the main fit; the other seeds add 38 fits. Total planned physical fits: 282; total logical evaluations: 360. This second panel estimates estimator randomness on one fixed pool, not training-selection variation.

Before scoring, save the complete config and all jobs, deterministic memberships, full executable source and test snapshots, input hashes, dependency versions and a run fingerprint. Resume requires identical inputs, code, environment and config and validates all existing result artifacts. Frozen source/config cannot change after scoring. Individual failures are retained with NaN scores and explicit status, never converted to safe predictions. Each fit's predictions contain only file IDs, score and status; labels are used only by the post-prediction evaluator. Convergence warnings and timing are preserved.

Report sklearn AP separately from trapezoidal PR area, plus workload at floor(0.05N), floor(0.10N), floor(0.20N): 54, 108 and 216 reviews. Exact score ties use uniform-boundary expected positive count and attainable range, provided by the existing evaluated metric utility. Report all 20 draw values, descriptive mean, standard deviation and quantiles by regime/method, and all six within-draw regime differences. Summaries are conditional on successful scoring; retain failures/coverage explicitly. Quantiles describe the frozen training-draw experiment and are **not confidence intervals for unseen projects or families**. There is no score pooling across methods or draws.

The random-ranking reference uses 10,000 uniformly sampled permutations with fixed seed 20261025, distinct random ranks, N=1,082 and K=21. Its exact expected AP is H_N/N + (K−1)(N−H_N)/(N(N−1)), approximately 0.02536, distinct from prevalence 21/1082. An exhaustive small-N test verifies the formula. The finite reference is descriptive only: the single dependent test component does not justify file-label exchangeability for an inferential permutation test. No p-values, rejection decisions, or new-family confidence intervals are computed. This reference cannot establish the reviewer's claim that the original AP differences are almost certainly noise.
