# Findings — what smart-contract security benchmarks measure (study V)

Protocol: `docs/PROTOCOLS.md`, section V (six dated amendments; 4–6 follow an external review). Runs: `results/README.md`, rows V1–V10.
Every number below is in the named run; the paper tables are generated by `scripts/v6_paper_tables_figures.py`.

* **SolidiFI is an exact superposition** of 50 original contracts and 44 templates (V1). Template search finds
  9,364 snippets; counts equal the BugLog rows in 349/350 files; removing the snippets gives the original token for
  token in all 350 files.
* **Labels vs weakness** (V1, author's reading + solc 0.5.17): snippets without the named weakness are 18% of
  Timestamp-Dependency, 26% of Unhandled-Exceptions, 56% of tx.origin. Two Unhandled-Exceptions templates and one
  tx.origin template contain no CALL opcode. Seven of twelve reentrancy templates use `send`/`transfer` ("limited").
* **Unchecked-Send is not an unchecked call.** SolidiFI's own evaluator maps it to SWC-105. Studies C2/C3 (and the
  book chapter that uses them) merged it into "unchecked"; with the merged mapping Slither's file recall is 0.50
  instead of 1.00.
* **Learned detectors** (V2): standard AP 0.996–1.000; reduced to one template ("seen") pattern models drop to
  0.58–0.95; leave-one-template-out lowers lex_raw by 0.15–0.32. Templates read as yes / limited / no get seen AP
  0.98 / 0.998 / 0.96 (lex_raw).
* **Three-level reading** (`data/audit/template_three_levels.csv`, V7b): share of snippets read as *no* at the
  operation / weakness / exploit level — UE 9/26/72%, tx.origin 56/56/56%, Timestamp 0/18/37%, Reentrancy 0/0/71%,
  Overflow 0/0/56%. Four LLM readers (Grok, Gemini, Qwen, DeepSeek; not human experts) vs our weakness reading:
  Cohen κ 0.40–0.66, Fleiss κ 0.57; they answer "operation: yes" for all templates, including those without CALL.
* **Paired edits** (V10): renaming benchmark identifiers removes 92–100% of the lex_raw score gap in every class;
  fixing the arithmetic templates changes no model's score (P(vuln > fixed) 0.48–0.62); reentrancy / unchecked fixes
  remove part of the gap, model-dependent; timestamp / tx.origin fixes remove the keyword.
* **Analyser controls** (V8, 15 own contracts): Mythril without `--solv` silently disables its integer module
  offline; with `--solv` it flags the overflow (and also the fixed reentrancy contract). Slither flags every
  vulnerable and no fixed version of its classes; SmartCheck misses unchecked call/send and tx.origin in 0.5 syntax.
* **Analysers** (V4/V5, Mythril rerun `v4m_20261103` with `--solv`, Slither on DAppSCAN `v4d_20261103`): Slither
  SolidiFI reentrancy recall 1.00 per file, 0.29 per snippet, 1.00 per snippet with all detectors (SmartBugs
  precision then 0.76 → 0.50). Per template, Slither's snippet recall is 0 or 1. Mythril (350/350 SolidiFI files
  analysed) file / snippet recall: reentrancy 0.62/0.06, unchecked 0.78/0.21, arithmetic 0.62/0.06 (only on the four
  overflow templates read as yes); SmartBugs arithmetic P 0.27 / R 0.80. Slither `arbitrary-send-eth` finds every
  Unchecked-Send snippet (file P 0.20). Slither on DAppSCAN compiles 380/948 files; on those it flags 32/36 audited
  reentrancy and 10/11 timestamp files (P 0.18 / 0.07), 1/28 unchecked; end-to-end recall 0.28.
  SmartCheck on audited DAppSCAN files: timestamp 0/36, unchecked P 0.10 / R 0.09 at base rate 0.078.
* **Frozen transfer** (V3, V9): SolidiFI CV is 1.000 for all nine candidates, so selection is undetermined. Frozen vs
  target-best: observed oracle gap 0.148 AP on average; SolidiFI→SmartBugs reentrancy 0.496 (cluster CI 0.34–0.65,
  random-order AP 0.24) vs 0.784 (the C2 number). Frozen SolidiFI model on DAppSCAN: permutation p 0.11–0.52 for all
  four classes (within projects 0.10–0.80) — no evidence of a better-than-random ranking; the best candidates reach
  p ≤ 0.004 (not identifiable from the source). 8/16 frozen combinations have p < 0.05.
* **Budgets** (V5 `v5_20261104_043212`): against a random order among the tool's alarms, the hybrid helps for Mythril
  arithmetic with the SolidiFI model (k=20: 0.73 vs 0.36, CI 0.14–0.53) and Slither timestamp (k=5: 4/5 positives,
  CI 0.17–0.82); Slither reentrancy CI reaches 0 (0.00–0.20); with the DAppSCAN model the Mythril arithmetic hybrid is
  worse (−0.47..−0.23). Preliminary (few positives).
