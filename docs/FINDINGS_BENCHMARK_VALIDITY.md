# Findings — what smart-contract security benchmarks measure (study V)

Protocol: `docs/PROTOCOLS.md`, section V (three dated amendments). Runs: `results/README.md`, rows V1–V6.
Every number below is in the named run; the paper tables are generated by `scripts/v6_paper_tables_figures.py`.

* **SolidiFI is an exact superposition** of 50 original contracts and 44 templates (V1). Template search finds
  9,364 snippets; counts equal the BugLog rows in 349/350 files; removing the snippets gives the original token for
  token in all 350 files.
* **Labels vs weakness** (V1, author's reading + solc 0.5.17): snippets without the named weakness are 18% of
  Timestamp-Dependency, 26% of Unhandled-Exceptions, 56% of tx.origin. Two Unhandled-Exceptions templates and one
  tx.origin template contain no CALL opcode. Seven of twelve reentrancy templates use `send`/`transfer` ("limited").
* **Unchecked-Send is not an unchecked call.** SolidiFI's own evaluator maps it to SWC-105. Studies C2/C3 (and the
  book chapter that uses them) merged it into "unchecked"; with the merged mapping Slither's file recall is 0.50
  instead of 1.00.
* **Learned detectors** (V2): standard AP 0.996–1.000; reduced to one template ("seen") pattern models drop to
  0.58–0.95; leave-one-template-out lowers lex_raw by 0.15–0.32. Templates read as yes / limited / no get seen AP
  0.98 / 0.998 / 0.96 (lex_raw).
* **Analysers** (V4/V5): Slither SolidiFI reentrancy recall 1.00 per file, 0.29 per snippet, 1.00 per snippet with
  all detectors (SmartBugs precision then 0.76 → 0.50). Per template, Slither's snippet recall is 0 or 1. Mythril
  reports no SWC-101 finding on any file. SmartCheck on audited DAppSCAN files: timestamp 0/36, unchecked P 0.10 /
  R 0.09 at base rate 0.078.
* **Frozen transfer** (V3): SolidiFI CV is 1.000 for all nine candidates, so selection is undetermined. Frozen vs
  target-best: mean gap 0.148 AP; SolidiFI→SmartBugs reentrancy 0.496 vs 0.784 (the C2 number). No frozen
  SolidiFI model beats chance on DAppSCAN.
* **Budgets** (V5): hybrid (tool alarms ordered by a model) beats the tool at small k for Slither reentrancy,
  timestamp and unchecked calls; it is worse than Mythril's own ordering for reentrancy.
